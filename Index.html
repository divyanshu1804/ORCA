Problem Statement 06 — Technical Design Document

ORCA — Marine EcOsystem Reasoning with Collaborative Agents

A multi-agent AI system that answers marine and ocean-domain queries by decomposing a question, routing it to specialized reasoning agents, retrieving evidence from live and archival sources, and synthesizing a grounded, citation-backed response — built on LangGraph, RAG, and tool-calling agents.

02

Agent Orchestration Graph (LangGraph)

The orchestrator is modeled as an explicit state graph rather than a single prompt. Each node reads and writes a shared state object; conditional edges decide which agent runs next, and the graph can loop back to re-plan if retrieved evidence is insufficient.

03

Agent Roster

Each agent is a narrow, tool-using specialist. The orchestrator composes them per query instead of relying on one monolithic model call.

Control

Orchestrator / Planner Agent

Decomposes the incoming query, decides which specialist agents to invoke, and manages shared state across the graph.

  • Input: raw user query
  • Tools: LangGraph state machine, LLM planner
  • Output: execution plan, agent calls
Specialist

Weather Agent

Fetches and interprets meteorological conditions relevant to the query region and time window.

  • Tools: IMD / weather APIs
  • Output: structured weather summary
Specialist

Ocean Data Agent

Analyzes ocean-related parameters — sea surface temperature, salinity, currents, wave height — from buoy and satellite feeds.

  • Tools: INCOIS data services, satellite feeds
  • Output: ocean-parameter readings
Specialist

Geospatial Agent

Performs location resolution, region lookups, and spatial reasoning over maps and GIS layers.

  • Tools: Bhuvan / GIS services, geocoding
  • Output: spatial context, coordinates, region metadata
Specialist

Knowledge / RAG Agent

Retrieves relevant passages from a vector store of marine research, reports, and domain documentation to ground the answer.

  • Tools: embedding model, vector database
  • Output: retrieved passages with source metadata
Control

Synthesis / Reasoning Agent

Combines outputs from all invoked agents into a single coherent, evidence-based answer, checking for consistency and gaps.

  • Input: outputs of all specialist agents
  • Output: draft response with citations
Control

Response & Citation Agent

Formats the final response, attaches sources, and flags low-confidence answers for re-planning or human review.

  • Output: final user-facing answer

08

Grounding & Reliability Loop

Before an answer reaches the user, it passes a grounding check and a confidence filter — if either fails, the graph either replans or escalates instead of returning an unsupported answer.

fig 08 · reliability flow
flowchart LR RESP["Draft Response"] --> GC["Grounding / Citation Check"] GC -->|"fail"| REPLAN["Trigger Replan"] REPLAN --> ORCH3["Orchestrator"] GC -->|"pass"| SAFE["Confidence Filter"] SAFE -->|"low confidence"| HUMAN["Flag for Human Review"] SAFE -->|"pass"| FINAL["Final Answer to User"]
